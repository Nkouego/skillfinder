# 🎯 SkillFinder - Plateforme de Gestion du Recrutement

SkillFinder est une application web JEE permettant à l'entreprise **Kozao Africa** de centraliser les offres d'emploi, les candidatures et les CV. Elle offre un suivi structuré du processus de recrutement à travers un pipeline de statuts dynamique.

---

## 🚀 Fonctionnalités Principales

### 💼 Espace Recruteur & Administrateur RH
* **Gestion des Offres :** Création, publication et modification des offres d'emploi (CRUD).
* **Pipeline de Candidatures :** Suivi et modification du statut des candidats (*Reçue, En analyse, Entretien, Acceptée, Refusée*).
* **Moteur de Recherche :** Filtrage des profils par compétences et mots-clés.
* **Tableau de Bord :** Statistiques globales sur l'évolution des recrutements.

### 📝 Espace Candidat
* **Consultation :** Visualisation des offres d'emploi disponibles.
* **Postuler :** Dépôt de candidature avec import du fichier CV.
* **Suivi :** Consultation en direct de l'état d'avancement du dossier.

---

## 🛠️ Technologies Utilisées

L'application respecte scrupuleusement l'architecture JEE standard :
* **Backend :** Java EE (Servlets, CDI, JPA, Hibernate)
* **Frontend :** Pages JSP, JSTL, CSS (Tailwind)
* **Gestionnaire de projet :** Maven 3
* **Base de données :** PostgreSQL
* **Serveur d'application :** Apache Tomcat

---

## 📦 Installation

### Prerequisites
* Java JDK 17 (ou version supérieure)
* Maven installé
* Un serveur de base de données POSTGRESQL opérationnel
